# Qedge-Ai

A world-class AI-powered Stock Market Prediction and Analysis Platform that uses advanced Machine Learning, Computer Vision, and NLP to predict whether a stock or crypto asset is likely to move UP, DOWN, or SIDEWAYS.

## Features
- **Live Trading Terminal:** Simulated OHLCV candlestick charting with live technical indicators.
- **AI Ensemble Predictions:** Combines LSTM, Transformer, XGBoost, and RL Agents to generate trading signals and confidence scores.
- **Vision Analysis Engine:** Upload chart images for automated pattern recognition (e.g., Head & Shoulders) and Support/Resistance zone detection.
- **NLP Sentiment Engine:** Aggregates FinBERT sentiment from news, Twitter, and Reddit to gauge market mood.
- **Walk-Forward Backtesting:** Run strategies over historical data and visualize equity curves and performance metrics.
- **Paper Trading Portfolio:** Manage simulated positions with real-time AI signal tracking.
